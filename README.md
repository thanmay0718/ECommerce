# ECommerce Project

This repository contains a full-stack e-commerce application with separate frontend and backend folders.

## Project Structure

- Frontend/ - React + Vite frontend application
- Backend/ - Spring Boot backend API

## Tech Stack

- Frontend: React, Vite, Redux, Material UI
- Backend: Java, Spring Boot, Spring Security, JPA, PostgreSQL

## Run locally

### Frontend
```bash
cd Frontend
npm install
npm run dev
```

### Backend
```bash
cd Backend
./mvnw spring-boot:run
```
